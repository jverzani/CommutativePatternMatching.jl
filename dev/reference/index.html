    CommutativePatternMatching.Rule

    Rule

    A rule created by @rule. Call it on a subject to rewrite it: rule(sub) returns the rewritten term, or nothing if sub does not match.

    CommutativePatternMatching._eachmatch — Tuple{Any, Any}

    source 
    _eachmatch(pat, sub)

    Return a vector of the matches of the pattern pat to the subject sub, each a dictionary from wildcard names to their values. The vector is empty if there is no match.

    CommutativePatternMatching._rewrite — Tuple{Base.ImmutableDict{Symbol, Any}, Any}

    source 
    _rewrite(σ, rhs, [S])

    Rewrite the template rhs using the match σ.

    If rhs is a function, it is called on σ, as for a rule from @rule.

    If rhs is an expression, its wildcards are replaced by their values. For an Expr subject (S == Expr) the result is an expression. Otherwise each call is evaluated: an operation given by name is looked up in Main and Base, so to use a function from another module use @rule, or splice the function into the template (:($f(~x))).

    The subject type S is found from the values in σ if not given.

    CommutativePatternMatching.@pattern — Tuple{Any}

    source 
    @pattern expr

    Create a pattern from expr, as :(expr) would, except each guard of a wildcard (~x::pred, ~~x::pred, ~~~x::pred) is evaluated where the macro is called and spliced into the pattern as a value.

    A guard in a quoted pattern, :(~x::isfoo), is looked up by name in Main and Base when the pattern is matched, so a predicate defined in another package is not found. With @pattern the guard is resolved in the calling module, as is any function a guard such as (u -> isfoo(u)) refers to.

    Values may be interpolated with $, as with a quoted expression.

    Examples

    julia> module Ext
           using CommutativePatternMatching
           isfoo(x) = x == :a
           pat = @pattern sin(~x::isfoo)
       end;

julia> CommutativePatternMatching._eachmatch(Ext.pat, :(sin(a)))
1-element Vector{Base.ImmutableDict{Symbol, Any}}:
 Base.ImmutableDict(:x => :a)

    CommutativePatternMatching.@rule — Tuple{Any}

    source 
    @rule lhs => rhs

    Create a rule which rewrites a subject matching the pattern lhs into rhs, with the wildcards of rhs replaced by their matched values.

    lhs is a pattern, as for @pattern. rhs is Julia code: it is compiled into a function of the match where the macro is called, so functions and variables it refers to are those of the calling module. A segment (~~x) is replaced by its tuple.

    For a symbolic subject rhs is evaluated; for an Expr subject, the matched values are substituted into rhs and an Expr is returned.

    Examples

    julia> using CommutativePatternMatching, SymEngine

julia> @vars x;

julia> r = @rule (~x)^(~n::isinteger) => (~x)^(~n + 1) / (~n + 1);

julia> r(x^2)
(1/3)*x^3

julia> r(:(x^2))
:(x ^ (2 + 1) / (2 + 1))

julia> r(sin(x)) === nothing
true
